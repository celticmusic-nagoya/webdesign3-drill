# 先生へ：最初にお読みください

このフォルダは、学習アプリ本体と今後の編集に必要なソース一式です。GitHubの登録・ログインは不要です。

1. ZIPを展開し、app/index.html をダブルクリックしてください。通信なしでも閲覧・演習できます。
2. 更新したい場合、展開前のZIPをバックアップとして保管してください。
3. 先生のChatGPTにこの引継ぎZIP（または source/ をZIPにしたもの）と、新しい教材PDF・修正要望を添付します。容量制限やZIPの処理制限がある場合は source/ を複数に分け、ファイル一覧とフォルダ構造を添えます。
4. 下の初回指示を貼り付けてください。ChatGPTが実行環境を使える場合はソースを更新して再ビルドし、新しい引継ぎZIPを返すよう依頼します。できない場合は編集済みファイル・手順を受け取り、PCで適用します。
5. 学校のサーバーに載せる場合は、生成済み app/ の中身だけを学校の公開用フォルダに置き、URLで動作確認します。公開する教材の権利を事前確認してください。

## ChatGPTに渡す初回指示（以下をコピー）

あなたは職業訓練校の「ウェブデザイン技能検定3級 学習アプリ」の教材管理・開発・品質保証担当です。

添付された引継ぎZIPを展開し、source/ の README.md、AGENTS.md、docs/MAINTENANCE.md、docs/RELEASE_CHECKLIST.md、各教材とソースコードを読み取ってください。GitHubは使用しません。手元の source/ が正本であり、app/ は生成された配布版です。まず現在版のファイル構成、問題数、教材、実行環境、更新可能な範囲を確認してください。

今後は新しい教材PDF、問題・解答の追加、誤字訂正、解説充実、学習機能・UIの改訂をお願いします。原本・固定問題ID・保存互換性を守り、原本にない補完は明示してください。教材の正答・配布可否は私が判断します。変更前の版を保護し、source/ を修正して再ビルドし、オンライン相当・通信なしのブラウザQAを行ってください。

変更後は動作する app/、更新した source/、変更内容・QA・未確認事項を含む新しい引継ぎZIPを返してください。未実行の検査は完了と報告しないでください。実行ツールや依存関係が不足する場合、編集済みファイルと再現手順を返してください。学校サーバーへの公開は私の指示に従い、app/ だけを掲載する構成とします。学生の個人情報・成績個票・パスワードを配布物に含めないでください。

「c」は安全な次の作業を実行、「ok」は直前に明示した対象の承認です。
