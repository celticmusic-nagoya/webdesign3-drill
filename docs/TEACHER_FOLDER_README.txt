ウェブデザイン技能検定3級 学習アプリ
先生向け　はじめに

【1. すぐに使う】
app フォルダを開き、index.html をダブルクリックしてください。
ChromeまたはEdgeなどのブラウザで、インターネット接続なしでも学習できます。
PDFのページ送りは「前へ」「次へ」、左右の矢印キー、画像の左右端クリック、スマホのスワイプに対応しています。
アプリの利用にGitHubのアカウントやソフトのインストールは不要です。

【オンライン版】
「オンライン版QR.png」をスマートフォンで読み取ると、公開中のオンライン版を開けます。
URL: https://celticmusic-nagoya.github.io/webdesign3-drill/
学校サーバーへ移行する場合は、ChatGPTにQRと案内URLの更新も依頼してください。

【2. 教材追加・アプリの修正をChatGPTに依頼する】
同じフォルダにある「ChatGPT引継ぎパッケージ.zip」を、解凍せず先生ご自身のChatGPTに添付してください。
ZIP内に、AIへの引継ぎ指示・編集用ソース・教材原本・再生成手順・検査手順がすべて入っています。
添付時に「このZIPのAI_START.txtを読んで引き継いでください」と一言送ると確実です。
以後は新しい教材PDFや「第5回の教材を追加したい」などの希望を送るだけで相談・更新を進められます。
ChatGPTの実行環境やファイル容量の制限によって、ZIPを分割したりPCで再生成したりする必要がある場合があります。
更新前のフォルダ・ZIPを保管し、AIから返された新しい版を動作確認してから配布してください。

【3. 学校のサーバーに掲載する】
ChatGPTに「学校のサーバーに掲載したい」と依頼してください。
掲載するのは app フォルダの中身のみです。引継ぎZIPや編集用ソースは公開しないでください。
公開前に教材の配布権利を確認し、校内限定の場合はサーバー側のアクセス制限を使用してください。
学習記録は端末・ブラウザ内に保存され、学校での成績自動集計機能はありません。

【注意】
このフォルダ一式を保管してください。app/index.html は利用用、引継ぎZIPは更新・管理用です。
他の端末・URL・保存場所へ移動するとブラウザの学習記録が引き継がれない場合があります。
